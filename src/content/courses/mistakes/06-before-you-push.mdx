Reviewers catch mistakes, but it's faster (and kinder to your reviewer) if you catch them first. Run this list over your diff before every push. It covers every mistake in this course, plus a few habits.

<Concept name="The checklist" id="checklist">

**State**
1. No state is mutated: no `push`, `sort`, `splice`, `obj.x = …` on state. New arrays and objects only.
2. Updates that depend on the previous value use an updater: `setQty((q) => q + 1)`.
3. Nothing reads state right after setting it, expecting the new value.
4. No derived state: totals, filtered lists and flags are calculated during render.

**Lists and events**
5. Every `.map()` that returns JSX has a stable `key` from the data (not the index, not random).
6. Event props get functions: `onClick={handle}` or `onClick={() => handle(id)}`, never `onClick={handle(id)}`.

**Effects**
7. Every effect syncs with something outside React; otherwise it's a calculation or an event handler.
8. Dependency arrays are complete, and `react-hooks/exhaustive-deps` shows no warnings.
9. Every subscription, timer and listener is cleaned up; fetches ignore stale responses.

**Components**
10. No component is defined inside another component.
11. Hooks are called unconditionally, at the top level.
12. `&&` has a boolean on its left, so no stray `0`.

**Before pushing**
13. Buttons are `<button>`, inputs have labels, images have `alt`.
14. `npm run lint` and `npm test` pass, and you clicked through the change in the browser.
15. The console shows no React warnings (keys, act, controlled/uncontrolled, hydration).

</Concept>

<HowItWorks title="Let the tools do half of it">

Many items are automatic if the project is set up well: `eslint-plugin-react-hooks` (rules of hooks, dependencies), `react/jsx-key`, `jsx-a11y`, TypeScript for wrong props, and the React Compiler's lint rules for impure renders. Turn their warnings into errors in CI, so a red build stops the mistake before review. The checklist is for what tools can't judge: whether state is derived, whether an effect is needed, whether a key is really stable.

</HowItWorks>

Run the checklist on this cart and fix every bug: adding doesn't show, the total lags behind, Remove misbehaves, a key is unstable, and a timer is never cleaned up. The tests check the behavior; your code review should catch the rest.

```jsx starter file=/App.js
import { useEffect, useState } from "react";

const MENU = [
  { id: "c", name: "Coffee", price: 4 },
  { id: "t", name: "Tea", price: 2 },
];

export default function App() {
  const [lines, setLines] = useState([]);
  const [total, setTotal] = useState(0);
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    setTotal(lines.reduce((sum, l) => sum + l.price, 0));
  }, [lines]);

  useEffect(() => {
    const id = setInterval(() => setSeconds((s) => s + 1), 1000);
  }, []);

  function add(product) {
    lines.push({ ...product, id: product.id + "-" + lines.length });
    setLines(lines);
  }

  function remove(id) {
    setLines(lines.filter((l) => l.id !== id));
  }

  return (
    <>
      {MENU.map((p) => (
        <button key={p.id} onClick={() => add(p)}>Add {p.name}</button>
      ))}
      <ul>
        {lines.map((line, i) => (
          <li key={i}>
            {line.name} <button onClick={remove(line.id)}>Remove {line.name}</button>
          </li>
        ))}
      </ul>
      <p>Total: ${total}</p>
      <p>Session: {seconds}s</p>
    </>
  );
}
```

  fireEvent.click(screen.getByRole("button", { name: "Remove Coffee" }));

  expect(renderToString(<App />)).toMatch(/Total: \$(<!-- -->)?0/);

test("the timer is cleaned up on unmount", () => {
  const cleared = [];
  const targets = [...new Set([globalThis, window])];
  const originals = targets.map((t) => t.clearInterval);
  targets.forEach((t, i) => {
    t.clearInterval = (id) => {
      cleared.push(id);
      return originals[i].call(t, id);
    };
  });
  try {
    const { unmount } = render(<App />);
    unmount();
    expect(cleared.length).toBeGreaterThan(0);
  } finally {
    targets.forEach((t, i) => {
      t.clearInterval = originals[i];
    });
  }
});

```jsx solution file=/App.js
import { useEffect, useState } from "react";

const MENU = [
  { id: "c", name: "Coffee", price: 4 },
  { id: "t", name: "Tea", price: 2 },
];

let nextId = 1;

export default function App() {
  const [lines, setLines] = useState([]);
  const [seconds, setSeconds] = useState(0);
  const total = lines.reduce((sum, l) => sum + l.price, 0);

  useEffect(() => {
    const id = setInterval(() => setSeconds((s) => s + 1), 1000);
    return () => clearInterval(id);
  }, []);

  function add(product) {
    setLines([...lines, { ...product, id: `${product.id}-${nextId++}` }]);
  }

  function remove(id) {
    setLines(lines.filter((l) => l.id !== id));
  }

  return (
    <>
      {MENU.map((p) => (
        <button key={p.id} onClick={() => add(p)}>Add {p.name}</button>
      ))}
      <ul>
        {lines.map((line) => (
          <li key={line.id}>
            {line.name} <button onClick={() => remove(line.id)}>Remove {line.name}</button>
          </li>
        ))}
      </ul>
      <p>Total: ${total}</p>
      <p>Session: {seconds}s</p>
    </>
  );
}
```
