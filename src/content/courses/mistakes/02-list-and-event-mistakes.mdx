Two mistakes that show up in the very first lists and buttons you write.

<Concept name="Mistake 4: a missing key, or the index as the key" id="keys" warn>

<Compare
  wrong="No key (a warning), or the index (wrong item keeps the state when the list changes)"
  right="A stable id from the data"
  wrongFile="CartList.jsx"
  rightFile="CartList.jsx"
>

```jsx
{cart.map((line) => (
  <CartLine line={line} />
))}

{cart.map((line, i) => (
  <CartLine key={i} line={line} />
))}
```

```jsx
{cart.map((line) => (
  <CartLine key={line.id} line={line} />
))}
```

</Compare>

**Why:** keys tell React which item is which between renders. Without them, React matches items by position and warns. With the index, removing or inserting an item shifts every index after it, so a `CartLine`'s state (an open "edit" box, a typed note, focus) jumps to the **wrong** line. Use an id that belongs to the item. If the data has none, create one when the item is created (`crypto.randomUUID()`), never during render.

</Concept>

<Concept name="Mistake 5: calling the function in onClick" id="onclick" warn>

<Compare
  wrong="Runs during render: adds on every render, and often loops"
  right="Passes a function that runs on click"
  wrongFile="AddButton.jsx"
  rightFile="AddButton.jsx"
>

```jsx
<button onClick={add(product)}>Add</button>
<button onClick={setOpen(true)}>Open</button>
```

```jsx
<button onClick={() => add(product)}>Add</button>
<button onClick={() => setOpen(true)}>Open</button>
```

</Compare>

**Why:** whatever is inside `{ }` is evaluated during render. `add(product)` runs right away and its return value (`undefined`) becomes the handler. If it sets state, that state change triggers another render, which calls it again: React stops with "Too many re-renders". Pass a function: the function name alone (`onClick={handleAdd}`) when there are no arguments, or an arrow when there are.

</Concept>

<HowItWorks title="Spotting them in review">

Both have quick tells in a diff:

- `.map(` followed by JSX with **no `key=`**, or `key={i}` / `key={index}` / `key={Math.random()}`.
- `onSomething={name(` — an open parenthesis right after the function name inside an event prop.

ESLint catches both: `react/jsx-key` for keys, and React itself throws on the render loop. Code review catches the index keys the linter allows.

</HowItWorks>

<ReactExercise
  id="fix-list-events"
  variant="fix"
  title="Fix the order list"
  hints={[
    "Each `<li>` needs `key={order.id}` instead of the index.",
    "`onClick={cancel(order.id)}` runs during render: wrap it, `onClick={() => cancel(order.id)}`.",
  ]}
>

This order list crashes with **Too many re-renders**, and it uses index keys. Fix both: each Cancel button should cancel only its own order when clicked, and the list should use the orders' ids as keys.

```jsx starter file=/App.js
import { useState } from "react";

const INITIAL = [
  { id: "a1", name: "Coffee" },
  { id: "b2", name: "Tea" },
  { id: "c3", name: "Bagel" },
];

export default function App() {
  const [orders, setOrders] = useState(INITIAL);

  function cancel(id) {
    setOrders(orders.filter((o) => o.id !== id));
  }

  return (
    <ul>
      {orders.map((order, i) => (
        <li key={i}>
          {order.name} <button onClick={cancel(order.id)}>Cancel {order.name}</button>
        </li>
      ))}
    </ul>
  );
}
```

```jsx tests file=/App.test.js
import { fireEvent, render, screen } from "@testing-library/react";
import "@testing-library/jest-dom";
import App from "./App";

test("renders every order", () => {
  render(<App />);
  expect(screen.getAllByRole("listitem")).toHaveLength(3);
});

test("cancel removes only that order", () => {
  render(<App />);
  fireEvent.click(screen.getByRole("button", { name: "Cancel Tea" }));
  const names = screen.getAllByRole("listitem").map((li) => li.firstChild.textContent.trim());
  expect(names).toEqual(["Coffee", "Bagel"]);
});
```

```jsx solution file=/App.js
import { useState } from "react";

const INITIAL = [
  { id: "a1", name: "Coffee" },
  { id: "b2", name: "Tea" },
  { id: "c3", name: "Bagel" },
];

export default function App() {
  const [orders, setOrders] = useState(INITIAL);

  function cancel(id) {
    setOrders(orders.filter((o) => o.id !== id));
  }

  return (
    <ul>
      {orders.map((order) => (
        <li key={order.id}>
          {order.name} <button onClick={() => cancel(order.id)}>Cancel {order.name}</button>
        </li>
      ))}
    </ul>
  );
}
```
