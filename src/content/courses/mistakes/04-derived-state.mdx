The most common "it works but it's wrong" pattern in React codebases: **state that's a copy of other state**.

<Concept name="Mistake 8: storing derived state" id="derived" warn>

<Compare
  wrong="Three states that must be kept in sync by hand (and an effect to do it)"
  right="One state; the rest is calculated during render"
  wrongFile="Cart.jsx"
  rightFile="Cart.jsx"
>

```jsx
const [cart, setCart] = useState([]);
const [total, setTotal] = useState(0);
const [count, setCount] = useState(0);

useEffect(() => {
  setTotal(cart.reduce((s, l) => s + l.price * l.qty, 0));
  setCount(cart.reduce((n, l) => n + l.qty, 0));
}, [cart]);
```

```jsx
const [cart, setCart] = useState([]);

const total = cart.reduce((s, l) => s + l.price * l.qty, 0);
const count = cart.reduce((n, l) => n + l.qty, 0);
```

</Compare>

**Why:** derived state is a second copy of the truth, and copies drift. The effect version also renders **twice** per change (once with the new cart and the old total, then again), so for a moment the screen shows a wrong total. A calculation in the render body is always in sync, and it's usually so fast that it doesn't matter; if it's really expensive, wrap it in `useMemo`.

</Concept>

<Concept name="Its cousin: copying props into state" id="props-copy" warn>

<Compare
  wrong="Only reads the prop on the first render; later changes are ignored"
  right="Use the prop directly (or a key to reset on purpose)"
  wrongFile="PriceTag.jsx"
  rightFile="PriceTag.jsx"
>

```jsx
function PriceTag({ price }) {
  const [shown, setShown] = useState(price);
  return <strong>${shown}</strong>;
}
```

```jsx
function PriceTag({ price }) {
  return <strong>${price}</strong>;
}
```

</Compare>

**Why:** `useState(price)` uses its argument only once. When the parent later passes a new price, the component keeps the old one. Copy a prop into state only when you mean "start from this value, then the user edits it" (and name it that way: `initialPrice`). To start over when an id changes, give the component a `key`.

</Concept>

<HowItWorks title="The test: could you calculate it?">

Before adding a `useState`, ask: **can I compute this from props or other state?** If yes, it isn't state. Full name from first and last name, a filtered list from the list and the filter, "is the form valid" from the field values, the selected item from the list and a selected **id**: all derived. Keep the minimum in state (store the selected **id**, not a copy of the selected object), and compute the rest.

</HowItWorks>

This search keeps the filtered list and its count in state and syncs them with an effect, so for one render after each keystroke they're out of date (the tests check the very first render too). Remove both pieces of derived state and calculate them during render.

```jsx starter file=/App.js
import { useEffect, useState } from "react";

const products = [
  { id: 1, name: "Coffee" },
  { id: 2, name: "Iced coffee" },
  { id: 3, name: "Tea" },
];

export default function App() {
  const [query, setQuery] = useState("");
  const [visible, setVisible] = useState([]);
  const [count, setCount] = useState(0);

  useEffect(() => {
    const next = products.filter((p) => p.name.toLowerCase().includes(query.toLowerCase()));
    setVisible(next);
    setCount(next.length);
  }, [query]);

  return (
    <>
      <input aria-label="Search" value={query} onChange={(e) => setQuery(e.target.value)} />
      <p>{count} matches</p>
      <ul>
        {visible.map((p) => (
          <li key={p.id}>{p.name}</li>
        ))}
      </ul>
    </>
  );
}
```

```jsx tests file=/App.test.js
import { fireEvent, render, screen } from "@testing-library/react";
import "@testing-library/jest-dom";
import { renderToString } from "react-dom/server";
import App from "./App";

test("the very first render already shows every product", () => {
  // renderToString renders once, with no effects, like the first frame the user sees
  const html = renderToString(<App />);
  expect(html).toContain("Iced coffee");
  expect(html).toMatch(/3(<!-- -->)? matches/);
});

test("filters as you type", () => {
  render(<App />);
  fireEvent.change(screen.getByLabelText("Search"), { target: { value: "coffee" } });
  expect(screen.getAllByRole("listitem")).toHaveLength(2);
  expect(screen.getByText("2 matches")).toBeInTheDocument();
});
```

```jsx solution file=/App.js
import { useState } from "react";

const products = [
  { id: 1, name: "Coffee" },
  { id: 2, name: "Iced coffee" },
  { id: 3, name: "Tea" },
];

export default function App() {
  const [query, setQuery] = useState("");
  const visible = products.filter((p) => p.name.toLowerCase().includes(query.toLowerCase()));

  return (
    <>
      <input aria-label="Search" value={query} onChange={(e) => setQuery(e.target.value)} />
      <p>{visible.length} matches</p>
      <ul>
        {visible.map((p) => (
          <li key={p.id}>{p.name}</li>
        ))}
      </ul>
    </>
  );
}
```
