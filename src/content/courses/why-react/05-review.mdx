<SpotTheBug
  id="bug-review-mutate"
  bug={[4, 5]}
  prompt="Adding Coffee a second time doesn't update the screen. Click a buggy line. (UI = f(state))"
  explain="`line.qty++` changes the existing object, and `setCart(cart)` passes the very same array back. React sees the same value and skips the render. Build a new array: `setCart(cart.map(...))`."
  hint="Does React get a new array in the `if` branch?"
>

```jsx
function add(product) {
  const line = cart.find((l) => l.id === product.id);
  if (line) {
    line.qty++;
    setCart(cart);
  } else {
    setCart([...cart, { ...product, qty: 1 }]);
  }
}
```

</SpotTheBug>
