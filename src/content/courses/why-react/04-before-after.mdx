<Concept name="What React takes off your hands" id="what-react-does">

With React you stop writing three kinds of code:

1. **Finding elements** (`getElementById`, `querySelector`): your JSX already says where things go.
2. **Changing elements** (`textContent`, `append`, `remove`, `hidden`): React works out the changes when it commits.
3. **Remembering every spot** that depends on the data: each spot reads the state directly in the JSX, so it's always current.

What's left is the part that's actually about your app: **what the data is**, **how it changes**, and **what the page looks like for it**.

</Concept>

<Concept name="Imperative vs. declarative" id="imperative-declarative">

- **Imperative** code says *how*: "find the list, remove this item, set the total text to 9".
- **Declarative** code says *what*: "the total paragraph shows `total`". It doesn't care what was there before.

A recipe is imperative ("whisk the eggs, then…"); a photo of the finished cake is declarative. React lets you hand over the photo, and it does the baking.

</Concept>

<GoDeeper title="Isn't React slower than changing the DOM directly?">

A perfectly hand-tuned DOM update is as fast as it gets, and React can't beat it: React does the same DOM changes, plus the work of rendering and comparing. But:

- rendering produces plain JavaScript objects, which is very cheap compared with touching the DOM;
- React batches all the state changes from one event into a single render and commit;
- in real apps, hand-written updates rarely stay perfectly tuned; they get slower and buggier as features pile up.

So React's selling point isn't raw speed: it's **predictable, correct UI** that stays fast enough, with tools (`memo`, `useMemo`, transitions) for the rare spots that need more. You'll meet those in How React Works.

</GoDeeper>

This cart can add products but not remove them. Give every cart line a **Remove** button that takes it out of the cart. You only need to change the state: the total and the badge will follow on their own. The tests click the buttons for you; you can also try them in the preview.

```jsx starter file=/App.js
import { useState } from "react";

const products = [
  { id: 1, name: "Coffee", price: 4 },
  { id: 2, name: "Bagel", price: 3 },
  { id: 3, name: "Tea", price: 2 },
];

export default function App() {
  const [cart, setCart] = useState([]);
  const total = cart.reduce((sum, item) => sum + item.price, 0);

  function add(product) {
    setCart([...cart, product]);
  }

  // TODO: write remove(id)

  return (
    <main>
      <header>
        MiniShop <span className="badge" aria-label="Items in cart">{cart.length}</span>
      </header>
      <ul>
        {products.map((product) => (
          <li key={product.id}>
            {product.name} ${product.price}{" "}
            <button onClick={() => add(product)} disabled={cart.includes(product)}>
              Add
            </button>
          </li>
        ))}

import { fireEvent, render, screen, within } from "@testing-library/react";
import "@testing-library/jest-dom";
import App from "./App";

test("each cart line has a Remove button", () => {
  render(<App />);
  fireEvent.click(screen.getAllByRole("button", { name: "Add" })[0]);
  expect(screen.getByRole("button", { name: "Remove" })).toBeInTheDocument();
});

test("Remove takes the line out of the cart", () => {
  render(<App />);
  fireEvent.click(screen.getAllByRole("button", { name: "Add" })[0]);
  fireEvent.click(screen.getByRole("button", { name: "Remove" }));
  const cart = screen.getByRole("list", { name: "Cart" });
  expect(within(cart).queryByText(/Coffee/)).not.toBeInTheDocument();
});

test("the total and the badge follow", () => {
  render(<App />);
  const [coffee, bagel] = screen.getAllByRole("button", { name: "Add" });
  fireEvent.click(coffee);
  fireEvent.click(bagel);
  fireEvent.click(screen.getAllByRole("button", { name: "Remove" })[0]);
  expect(screen.getByText("Total: $3")).toBeInTheDocument();
  expect(screen.getByLabelText("Items in cart")).toHaveTextContent("1");
});
```

```jsx solution file=/App.js
import { useState } from "react";

const products = [
  { id: 1, name: "Coffee", price: 4 },
  { id: 2, name: "Bagel", price: 3 },
  { id: 3, name: "Tea", price: 2 },
];

export default function App() {
  const [cart, setCart] = useState([]);
  const total = cart.reduce((sum, item) => sum + item.price, 0);

  function add(product) {
    setCart([...cart, product]);
  }

  function remove(id) {
    setCart(cart.filter((item) => item.id !== id));
  }

  return (
    <main>
      <header>
        MiniShop <span className="badge" aria-label="Items in cart">{cart.length}</span>
      </header>
      <ul>
        {products.map((product) => (
          <li key={product.id}>
            {product.name} ${product.price}{" "}
            <button onClick={() => add(product)} disabled={cart.includes(product)}>
              Add
            </button>
          </li>
        ))}
      </ul>
      <h2>Cart</h2>
      <ul aria-label="Cart">
        {cart.map((item) => (
          <li key={item.id}>
            {item.name}{" "}
            <button onClick={() => remove(item.id)}>Remove</button>
          </li>
        ))}
      </ul>
      <p>Total: ${total}</p>
    </main>
  );
}
```
