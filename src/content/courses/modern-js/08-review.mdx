<Exercise
  id="store-total"
  title="The store total, from the API"
  hints={[
    "`await fetch(url)` first, then check `res.ok` and throw `new Error(\"HTTP \" + res.status)` if it's false.",
    "`await res.json()` gives the products array; `reduce` adds up their `price`.",
    "Return the total formatted with a dollar sign and `toFixed(2)`.",
  ]}
>

Write `async function getStoreTotal(url = "/api/products")`. It loads the products, adds up every `price`, and returns the total as text like `"$12.00"`. If the response isn't ok, throw an error with the message `HTTP <status>`.

```js starter
async function getStoreTotal(url = "/api/products") {
  return "$0.00";
}

console.log(await getStoreTotal());
```

```js tests
test("adds up every product price", async () => {
  expect(await getStoreTotal()).toBe("$12.00");
});

test("throws HTTP 404 for a missing URL", async () => {
  let message = "no error";
  try {
    await getStoreTotal("/api/missing");
  } catch (err) {
    message = err.message;
  }
  expect(message).toBe("HTTP 404");
});

test("returns a promise", () => {
  expect(getStoreTotal() instanceof Promise).toBe(true);
});
```

```js solution
async function getStoreTotal(url = "/api/products") {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  const products = await res.json();
  const total = products.reduce((sum, p) => sum + p.price, 0);
  return `$${total.toFixed(2)}`;
}

console.log(await getStoreTotal());
```

</Exercise>
