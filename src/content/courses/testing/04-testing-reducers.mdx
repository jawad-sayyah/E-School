Reducers are the easiest React code to test: they're **pure functions**. Give one a state and an action, check the state that comes back. No rendering, no DOM, no mocks.

<Concept name="One describe per reducer, one test per behavior" id="structure">

```js file=cartReducer.test.js
describe("cartReducer", () => {
  const tea = { id: 1, name: "Tea", price: 2 };

  test("added: a new product becomes a line with qty 1", () => {
    expect(cartReducer([], { type: "added", product: tea })).toEqual([{ ...tea, qty: 1 }]);
  });

  test("added: the same product again increases qty", () => {
    const cart = [{ ...tea, qty: 1 }];
    expect(cartReducer(cart, { type: "added", product: tea })).toEqual([{ ...tea, qty: 2 }]);
  });

  test("removed: takes the line out", () => {
    expect(cartReducer([{ ...tea, qty: 1 }], { type: "removed", id: 1 })).toEqual([]);
  });
});
```

- Name tests after the **action and the behavior**, so a failure reads like a sentence.
- Build the starting state right in the test (or with a small helper): each test stands on its own.
- Use `toEqual`: the reducer returns new arrays and objects.

</Concept>

<Concept name="Test that nothing was mutated" id="immutability">

A reducer that mutates its input can pass a naive test (the returned value looks right) and still break React, which compares old and new state. Freeze the input, or compare it after the call:

```js file=immutability.test.js
test("never mutates the previous state", () => {
  const cart = Object.freeze([Object.freeze({ id: 1, name: "Tea", price: 2, qty: 1 })]);
  const next = cartReducer(cart, { type: "added", product: { id: 1, name: "Tea", price: 2 } });
  expect(next).not.toBe(cart);           // a new array
  expect(cart[0].qty).toBe(1);          // the old line is untouched
});
```

`Object.freeze` makes any accidental `push` or `line.qty++` throw (in strict mode) or silently do nothing, so the test catches it either way.

</Concept>

<HowItWorks title="Why reducers deserve thorough tests">

The reducer holds the rules of your app's state: what adding twice does, what happens at quantity zero, whether an unknown product id is ignored. Those rules break silently in the UI (a wrong badge number), but a reducer test pinpoints them in milliseconds. A handful of reducer tests often covers more real logic than a dozen component tests. Test every action, plus the edge cases: unknown ids, zero and negative quantities, an empty state.

</HowItWorks>

Write tests for `cartReducer` that catch every buggy version. It handles `"added"`, `"removed"` and `"qtyChanged"` (a qty of 0 or less removes the line), and must never mutate the previous state.

```js code file=cartReducer.js
function cartReducer(cart, action) {
  switch (action.type) {
    case "added": {
      const line = cart.find((l) => l.id === action.product.id);
      if (line) return cart.map((l) => (l === line ? { ...l, qty: l.qty + 1 } : l));
      return [...cart, { ...action.product, qty: 1 }];
    }
    case "removed":
      return cart.filter((l) => l.id !== action.id);
    case "qtyChanged":
      if (action.qty <= 0) return cart.filter((l) => l.id !== action.id);
      return cart.map((l) => (l.id === action.id ? { ...l, qty: action.qty } : l));
    default:
      return cart;
  }
}
```

```js solution
const tea = { id: 1, name: "Tea", price: 2 };
const cake = { id: 2, name: "Cake", price: 4 };

describe("cartReducer", () => {
  test("added: a new product gets qty 1", () => {
    expect(cartReducer([], { type: "added", product: tea })).toEqual([{ ...tea, qty: 1 }]);
  });
  test("added: the same product again increases qty, without mutating", () => {
    const line = Object.freeze({ ...tea, qty: 1 });
    const cart = Object.freeze([line]);
    const next = cartReducer(cart, { type: "added", product: tea });
    expect(next).toEqual([{ ...tea, qty: 2 }]);
    expect(line.qty).toBe(1);
  });
  test("removed: takes out only that line", () => {
    const cart = [{ ...tea, qty: 1 }, { ...cake, qty: 1 }];
    expect(cartReducer(cart, { type: "removed", id: 1 })).toEqual([{ ...cake, qty: 1 }]);
  });
  test("qtyChanged: sets the quantity, and 0 removes the line", () => {
    const cart = [{ ...tea, qty: 1 }];
    expect(cartReducer(cart, { type: "qtyChanged", id: 1, qty: 5 })).toEqual([{ ...tea, qty: 5 }]);
    expect(cartReducer(cart, { type: "qtyChanged", id: 1, qty: 0 })).toEqual([]);
  });
});
```
