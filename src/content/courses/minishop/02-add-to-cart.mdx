A shop where you can't add anything isn't much of a shop. In this step every product gets an **Add** button. When it's clicked, the cart array changes, and then… nothing on the page changes, unless *you* go and update every place that shows the cart.

That's the **sync problem**: the data and the page are two separate things, and keeping them in step is your job. There are only three places to update here (the list, the total and the badge in the header). Imagine thirty.

The page now has products with **Add** buttons, and `shop.js` already adds to the cart and redraws the list. Write the two missing helpers in `cartUtils.js`, then make the total and the badge keep up.

```js starter file=/cartUtils.js
export function formatPrice(amount) {
  return "$" + amount.toFixed(2);
}

export function cartTotal(items) {
  return items.reduce((sum, item) => sum + item.price * item.qty, 0);
}

export function renderCart(items) {
  if (items.length === 0) return "<li>Your cart is empty.</li>";
  return items
    .map((item) => `<li>${item.name} × ${item.qty}: ${formatPrice(item.price * item.qty)}</li>`)
    .join("");
}
```

```js starter file=/shop.js
import { products } from "./products";
import { addToCart, cartTotal, formatPrice, renderCart } from "./cartUtils";

export function mountShop(root) {
  let cart = [];

  root.innerHTML = `
    <header>
      <h1>MiniShop</h1>
      <p>Cart: <span id="badge">0</span> items</p>
    </header>
    <h2>Products</h2>
    <ul id="products">
      ${products
        .map(
          (product) => `<li>${product.name} ${formatPrice(product.price)}
            <button data-id="${product.id}" aria-label="Add ${product.name}">Add</button></li>`,
        )
        .join("")}
    </ul>
    <h2>Your cart</h2>
    <ul id="cart">${renderCart(cart)}</ul>
    <p id="total">Total: ${formatPrice(cartTotal(cart))}</p>
  `;

  root.querySelector("#products").addEventListener("click", (event) => {
    const button = event.target.closest("button");
    if (!button) return;
    const product = products.find((p) => p.id === Number(button.dataset.id));
    cart = addToCart(cart, product);
    root.querySelector("#cart").innerHTML = renderCart(cart);
    // TODO: the badge and the total still show the old cart
  });
}
```

```js solution file=/cartUtils.js
export function formatPrice(amount) {
  return "$" + amount.toFixed(2);
}

export function cartTotal(items) {
  return items.reduce((sum, item) => sum + item.price * item.qty, 0);
}

export function cartCount(items) {
  return items.reduce((sum, item) => sum + item.qty, 0);
}

export function addToCart(items, product) {
  const existing = items.find((item) => item.id === product.id);
  if (existing) {
    return items.map((item) => (item.id === product.id ? { ...item, qty: item.qty + 1 } : item));
  }
  return [...items, { ...product, qty: 1 }];
}

export function renderCart(items) {
  if (items.length === 0) return "<li>Your cart is empty.</li>";
  return items
    .map((item) => `<li>${item.name} × ${item.qty}: ${formatPrice(item.price * item.qty)}</li>`)
    .join("");
}
```

```js solution file=/shop.js
import { products } from "./products";
import { addToCart, cartCount, cartTotal, formatPrice, renderCart } from "./cartUtils";

export function mountShop(root) {
  let cart = [];

  root.innerHTML = `
    <header>
      <h1>MiniShop</h1>
      <p>Cart: <span id="badge">0</span> items</p>
    </header>
    <h2>Products</h2>
    <ul id="products">
      ${products
        .map(
          (product) => `<li>${product.name} ${formatPrice(product.price)}
            <button data-id="${product.id}" aria-label="Add ${product.name}">Add</button></li>`,
        )
        .join("")}
    </ul>
    <h2>Your cart</h2>
    <ul id="cart">${renderCart(cart)}</ul>
    <p id="total">Total: ${formatPrice(cartTotal(cart))}</p>
  `;

  // Everything that shows the cart, in one place. Forget a line, and that part goes stale.
  function update() {
    root.querySelector("#cart").innerHTML = renderCart(cart);
    root.querySelector("#total").textContent = `Total: ${formatPrice(cartTotal(cart))}`;
    root.querySelector("#badge").textContent = String(cartCount(cart));
  }

  root.querySelector("#products").addEventListener("click", (event) => {
    const button = event.target.closest("button");
    if (!button) return;
    const product = products.find((p) => p.id === Number(button.dataset.id));
    cart = addToCart(cart, product);
    update();
  });
}
```

<HowItWorks title="Why this doesn't scale">

Count the places that must change when the cart changes: the list, the total and the badge. Now add what a real shop has: a mini-cart in the header, a "free shipping from $50" banner, disabled buttons for items at their stock limit, a checkout button that's hidden for an empty cart. Each one is another line in `update()`, and every new feature has to remember all of them.

There's a second, sneakier problem: `update()` rewrites the cart list with `innerHTML`, so if the cart had a quantity `<input>` with focus, the focus is gone after every change.

React flips the model. Instead of *"when X changes, go and change these five DOM nodes"*, you write *"given this data, the page looks like this"*, and React works out the DOM changes itself. That's the whole idea behind the next step.

</HowItWorks>
