The hard-coded cart in `App.js` has to go. A cart that changes is **state**: data that belongs to a component and makes React re-render when it changes. With state, the sync problem from step 2 disappears: you change the data, and React redraws everything that depends on it.

The cart lives in `App`, because both `ProductList` (which adds) and `Cart` (which shows and changes) need it. That's **lifting state up**: the state sits in the closest common parent, and the children get the data and callbacks as props.

```js starter file=/cartUtils.js
export function formatPrice(amount) {
  return "$" + amount.toFixed(2);
}

export function cartTotal(items) {
  return items.reduce((sum, item) => sum + item.price * item.qty, 0);
}

export function cartCount(items) {
  return items.reduce((sum, item) => sum + item.qty, 0);
}

export function addToCart(items, product) {
  const existing = items.find((item) => item.id === product.id);
  if (existing) {
    return items.map((item) => (item.id === product.id ? { ...item, qty: item.qty + 1 } : item));
  }
  return [...items, { ...product, qty: 1 }];
}

export function renderCart(items) {
  if (items.length === 0) return "<li>Your cart is empty.</li>";
  return items
    .map((item) => `<li>${item.name} × ${item.qty}: ${formatPrice(item.price * item.qty)}</li>`)
    .join("");
}
```

```jsx solution file=/App.js
import { useState } from "react";
import { products } from "./products";
import { addToCart } from "./cartUtils";
import ProductList from "./ProductList";
import Cart from "./Cart";

export default function App() {
  const [cart, setCart] = useState([]);

  function add(product) {
    setCart((items) => addToCart(items, product));
  }

  function changeQty(id, qty) {
    setCart((items) =>
      qty < 1
        ? items.filter((item) => item.id !== id)
        : items.map((item) => (item.id === id ? { ...item, qty } : item)),
    );
  }

  function remove(id) {
    setCart((items) => items.filter((item) => item.id !== id));
  }

  return (
    <main>
      <h1>MiniShop</h1>
      <ProductList products={products} onAdd={add} />
      <Cart items={cart} onChangeQty={changeQty} onRemove={remove} />
    </main>
  );
}
```

<HowItWorks title="What happens when you click +">

1. The button's handler calls `onChangeQty(2, 3)`, which is `App`'s `changeQty`.
2. `setCart(updater)` doesn't change anything yet. It **queues** the update and asks React for a re-render.
3. React calls `App()` again. This time `useState` runs the queued updater on the old cart and returns the new array.
4. `App` returns new JSX with the new cart; `Cart` re-renders and computes the new total from it.
5. React compares the new tree with the old one, and changes only the text of that line and of the total in the DOM.

No `update()` function, nothing to forget: every part that depends on the cart is recomputed from it. That's the sync problem from step 2, solved.

</HowItWorks>
