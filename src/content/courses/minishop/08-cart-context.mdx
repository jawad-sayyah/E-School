The shop needs a **cart badge** in the header. The header sits far from `App`'s cart state, and soon there will be pages (step 10) between them. Passing `items` and `dispatch` down through every component in between is called **prop drilling**, and it makes every middle component carry props it doesn't use.

**Context** lets a component provide a value to its whole subtree, and any component below can read it directly. You'll build two pieces:

- **`CartProvider`**: owns the cart (the `useReducer` and the saving effect move here from `App`) and provides it.
- **`useCart()`**: a custom hook that reads the context and returns a friendly API: `items`, `count`, `total`, `add`, `remove`, `setQty` and `clear`.

After this step, `ProductList`, `Cart` and `Header` take **no props** for the cart at all.

```js starter file=/cartUtils.js
export function formatPrice(amount) {
  return "$" + amount.toFixed(2);
}

export function cartTotal(items) {
  return items.reduce((sum, item) => sum + item.price * item.qty, 0);
}

export function cartCount(items) {
  return items.reduce((sum, item) => sum + item.qty, 0);
}

export function addToCart(items, product) {
  const existing = items.find((item) => item.id === product.id);
  if (existing) {
    return items.map((item) => (item.id === product.id ? { ...item, qty: item.qty + 1 } : item));
  }
  return [...items, { ...product, qty: 1 }];
}

export function renderCart(items) {
  if (items.length === 0) return "<li>Your cart is empty.</li>";
  return items
    .map((item) => `<li>${item.name} × ${item.qty}: ${formatPrice(item.price * item.qty)}</li>`)
    .join("");
}
```

```js starter file=/cartReducer.js
import { addToCart } from "./cartUtils";

export function cartReducer(items, action) {
  switch (action.type) {
    case "add":
      return addToCart(items, action.product);
    case "remove":
      return items.filter((item) => item.id !== action.id);
    case "setQty":
      if (action.qty < 1) return items.filter((item) => item.id !== action.id);
      return items.map((item) => (item.id === action.id ? { ...item, qty: action.qty } : item));
    case "clear":
      return [];
    default:
      throw new Error(`Unknown action: ${action.type}`);
  }
}
```

```jsx solution file=/CartContext.js
import { createContext, useContext, useEffect, useReducer } from "react";
import { cartReducer } from "./cartReducer";
import { cartCount, cartTotal } from "./cartUtils";
import { loadCart, saveCart } from "./storage";

const CartContext = createContext(null);

export function CartProvider({ children }) {
  const [items, dispatch] = useReducer(cartReducer, undefined, loadCart);

  useEffect(() => {
    saveCart(items);
  }, [items]);

  return <CartContext value={{ items, dispatch }}>{children}</CartContext>;
}

export function useCart() {
  const context = useContext(CartContext);
  if (!context) throw new Error("useCart must be used inside <CartProvider>");
  const { items, dispatch } = context;
  return {
    items,
    count: cartCount(items),
    total: cartTotal(items),
    add: (product) => dispatch({ type: "add", product }),
    remove: (id) => dispatch({ type: "remove", id }),
    setQty: (id, qty) => dispatch({ type: "setQty", id, qty }),
    clear: () => dispatch({ type: "clear" }),
  };
}
```

<HowItWorks title="Who re-renders when the cart changes?">

When `CartProvider`'s state changes, it renders again and passes a **new** `{ items, dispatch }` object to `value`. React then re-renders every component that reads that context with `useContext`, wherever it is in the tree, even if the components in between skipped rendering.

For MiniShop that's exactly right: the badge, the product list and the cart all show cart data. In a big app with a context read by hundreds of components, you'd split it (for example one context for `items` and one for the stable `dispatch`), or use a store like **Zustand**, where each component subscribes only to the slice it uses:

```js
const count = useCartStore((state) => cartCount(state.items));
```

Context is built into React and perfect for app-wide values that change now and then (the cart, the theme, the signed-in user). Reach for a store when updates are frequent and many components read small pieces.

```jsx code file=/CartContext.js
  const context = useContext(CartContext);
  if (!context) throw new Error("useCart must be used inside <CartProvider>");
  const { items, dispatch } = context;
  return {
    items,
    count: cartCount(items),
    total: cartTotal(items),
    add: (product) => dispatch({ type: "add", product }),
    remove: (id) => dispatch({ type: "remove", id }),
    setQty: (id, qty) => dispatch({ type: "setQty", id, qty }),
    clear: () => dispatch({ type: "clear" }),
  };
}
```
