Last lesson, every `ProductCard` said "Coffee". **Props** fix that: they're the arguments of a component. The parent passes them like HTML attributes, and the component receives them as one object.

<Concept name="Passing props" id="passing-props">

<ReactPlayground height={400}>

```jsx file=/App.js
function ProductCard({ name, price, onSale }) {
  return (
    <article className="card">
      <h2>{name}</h2>
      <p>${price.toFixed(2)}</p>
      {onSale && <span className="sale">Sale</span>}
    </article>
  );
}

export default function App() {
  return (
    <div className="grid">
      <ProductCard name="Coffee" price={4} />
      <ProductCard name="Bagel" price={3} onSale />
      <ProductCard name="Tea" price={2.5} />
    </div>
  );
}
```

```css file=/styles.css
body { font-family: system-ui, sans-serif; padding: 16px; }
.grid { display: flex; gap: 12px; flex-wrap: wrap; }
.card { border: 1px solid #ddd; border-radius: 12px; padding: 12px 16px; min-width: 120px; }
.card h2 { margin: 0; font-size: 18px; }
.card p { margin: 4px 0; color: #555; }
.sale { background: #ffd93d; border-radius: 6px; padding: 2px 8px; font-size: 12px; font-weight: 700; }
```

</ReactPlayground>

- Strings can use quotes: `name="Coffee"`. Anything else needs braces: `price={4}`, `tags={["hot"]}`, `onAdd={handleAdd}`.
- A prop with no value, like `onSale`, is `true`.
- The component receives **one object**, `{ name: "Coffee", price: 4 }`. Destructuring it in the parameter list, `({ name, price })`, is the usual style.

</Concept>

<Concept name="Default values" id="default-props">

Give a prop a default with destructuring's `=`. The default is used when the parent doesn't pass that prop (or passes `undefined`).

```jsx file=Price.jsx
function Price({ amount, currency = "$" }) {
  return <span>{currency}{amount.toFixed(2)}</span>;
}

<Price amount={4} />                // $4.00
<Price amount={4} currency="€" />   // €4.00
```

</Concept>

<Concept name="Props are read-only" id="read-only">

A component must never change its props. `props.price = 5` or `name = name.trim()` on a prop breaks the one-way flow of data: the parent owns that value. If a component needs a different value, it calculates a **new** variable (`const label = name.trim()`), or the parent passes something else.

<Callout type="react">
Data flows **down**: parents pass props to children. When a child needs to change something, the parent passes a function as a prop (like `onAdd`), and the child calls it. That's the Events lesson.
</Callout>
</Concept>

<Concept name="children" id="children">

Whatever you put **between** a component's opening and closing tags arrives as a special prop called `children`. It's how you build wrappers: cards, panels, modals, layouts.

<ReactPlayground height={300}>

```jsx file=/App.js
function Panel({ title, children }) {
  return (
    <section className="panel">
      <h2>{title}</h2>
      {children}
    </section>
  );
}

export default function App() {
  return (
    <>
      <Panel title="Cart">
        <p>Your cart is empty.</p>
      </Panel>
      <Panel title="Today's special">
        <p>Iced coffee, $3.50</p>
        <button>Add to cart</button>
      </Panel>
    </>
  );
}
```

```css file=/styles.css
body { font-family: system-ui, sans-serif; padding: 16px; }
.panel { border: 1px solid #ddd; border-radius: 12px; padding: 4px 16px 12px; margin-bottom: 12px; }
.panel h2 { font-size: 16px; color: #0e7490; }
```

</ReactPlayground>
</Concept>

<HowItWorks title="What React does with props">

`<ProductCard name="Tea" price={2.5} />` becomes `jsx(ProductCard, { name: "Tea", price: 2.5 })`. When React renders, it calls `ProductCard({ name: "Tea", price: 2.5 })` and uses what it returns. Children go into the same object: `<Panel title="Cart"><p>Empty</p></Panel>` calls `Panel({ title: "Cart", children: <p>Empty</p> })`.

When a parent re-renders with different props, React calls the child again with the new object. That's why a component's output always matches the props it was given.

</HowItWorks>

<GoDeeper title="Typed props with TypeScript">

In a TypeScript project (`.tsx` files), you describe the shape of the props with a type. Then your editor autocompletes them and flags a missing or wrong prop before you even run the code.

```tsx file=ProductCard.tsx
type ProductCardProps = {
  name: string;
  price: number;
  onSale?: boolean;            // ? means optional
  children?: React.ReactNode;  // anything React can render
};

function ProductCard({ name, price, onSale = false, children }: ProductCardProps) {
  return <article>{name} ${price}{onSale && " (sale)"}{children}</article>;
}

<ProductCard name="Tea" price="2.5" />
//                      ~~~~~ Error: Type 'string' is not assignable to type 'number'.
```

The TypeScript with React course covers this in depth.

</GoDeeper>

<ReactExercise

Write `Price` in `Price.js`. It takes an `amount` (a number) and an optional `currency` that defaults to `"$"`, and shows the amount with two decimals: `<Price amount={4} />` shows **$4.00**, and `<Price amount={2.5} currency="€" />` shows **€2.50**.

```jsx starter file=/Price.js
export default function Price(props) {
  return <span className="price">?</span>;
}
```

```jsx starter file=/App.js
import Price from "./Price";

export default function App() {
  return (
    <ul>
      <li>Coffee <Price amount={4} /></li>
      <li>Croissant <Price amount={2.5} currency="€" /></li>
      <li>Cake <Price amount={12.999} /></li>
    </ul>
  );
}
```

```jsx tests file=/Price.test.js
import { render, screen } from "@testing-library/react";
import "@testing-library/jest-dom";
import Price from "./Price";

test("shows dollars with two decimals by default", () => {
  render(<Price amount={4} />);
  expect(screen.getByText("$4.00")).toBeInTheDocument();
});

test("uses the currency prop", () => {
  render(<Price amount={2.5} currency="€" />);
  expect(screen.getByText("€2.50")).toBeInTheDocument();
});

test("rounds to two decimals", () => {
  render(<Price amount={12.999} />);
  expect(screen.getByText("$13.00")).toBeInTheDocument();
});
```

```jsx solution file=/Price.js
export default function Price({ amount, currency = "$" }) {
  return (
    <span className="price">
      {currency}
      {amount.toFixed(2)}
    </span>
  );
}
```
