UIs constantly depend on data: show "Sold out" when stock is 0, a spinner while loading, a different button when the user is logged in. Since JSX is JavaScript, you choose what to render with ordinary JavaScript.

<Concept name="Four ways to choose" id="four-ways">

<ReactPlayground height={420}>

```jsx file=/App.js
import { useState } from "react";

function StockNote({ stock }) {
  // 1. if + early return: whole different output
  if (stock === 0) return <p className="out">Sold out</p>;

  return (
    <p>
      {/* 2. ternary: one of two things */}
      {stock < 5 ? `Only ${stock} left!` : "In stock"}
      {/* 3. &&: something or nothing */}
      {stock > 20 && <span className="tag">Bestseller</span>}
    </p>
  );
}

export default function App() {
  const [stock, setStock] = useState(3);
  return (
    <>
      <label>
        Stock: <input type="number" min="0" value={stock} onChange={(e) => setStock(Number(e.target.value))} />
      </label>
      <StockNote stock={stock} />
      {/* 4. a class that depends on data */}
      <button className={stock === 0 ? "btn disabled" : "btn"} disabled={stock === 0}>
        Add to cart
      </button>
    </>
  );
}
```

```css file=/styles.css
body { font-family: system-ui, sans-serif; padding: 16px; }
.out { color: #c0392b; font-weight: 700; }
.tag { background: #ffd93d; border-radius: 6px; padding: 2px 8px; margin-left: 8px; font-size: 12px; }
.btn { background: #61dafb; border: 0; border-radius: 8px; padding: 8px 14px; font-weight: 600; }
.btn.disabled { background: #ddd; color: #888; }
```

</ReactPlayground>

Change the stock to 0, 3, 10 and 25 to see each branch.

1. **`if` with an early return** when the whole output is different.
2. **The ternary `a ? b : c`** to pick one of two things inside JSX.
3. **`cond && <X />`** to show something or nothing.
4. **Returning `null`** (or `false`, `undefined`) renders nothing at all.

</Concept>

<Concept name="The && trap: a stray 0" id="and-trap">

`&&` returns its **left side** when the left side is falsy. React renders `false`, `null` and `undefined` as nothing, but it renders the number **`0`** as text.

<Compare
  wrong="With an empty cart, a lonely 0 appears on the page"
  right="A real boolean on the left, so nothing renders"
  wrongFile="trap.jsx"
  rightFile="fixed.jsx"
>

```jsx
{cart.length && <p>{cart.length} items</p>}
```

```jsx
{cart.length > 0 && <p>{cart.length} items</p>}
```

</Compare>

Make the left side of `&&` a real boolean (`> 0`, `!== ""`, `Boolean(x)`), or use a ternary with `null`.

</Concept>

<HowItWorks title="What React renders for each value">

| Value in JSX | What shows |
| --- | --- |
| `"text"`, `42` | the text or number |
| `0`, `NaN` | `0`, `NaN` (they're numbers!) |
| `true`, `false`, `null`, `undefined` | nothing |
| an element `<p />` | the element |
| an array | each item, in order |
| a plain object `{ a: 1 }` | an error: objects aren't valid children |

That table explains every conditional pattern: a ternary and `&&` are just expressions that end up as one of these values.

</HowItWorks>

<GoDeeper title="Too many conditions? Use a lookup or a component">

When a component has three or more states (loading, error, empty, ready), nested ternaries get hard to read. Two cleaner options:

```jsx file=Status.jsx
// Early returns, one per state
function OrderStatus({ status }) {
  if (status === "loading") return <Spinner />;
  if (status === "error") return <ErrorMessage />;
  if (status === "empty") return <p>No orders yet.</p>;
  return <OrderList />;
}

// A lookup object for labels and colors
const BADGE = {
  paid: { label: "Paid", color: "green" },
  shipped: { label: "Shipped", color: "blue" },
  refunded: { label: "Refunded", color: "gray" },
};
const { label, color } = BADGE[order.status];
```

Write `StockLabel` in `StockLabel.js`. It gets a `stock` number and shows:

- **Sold out** when stock is 0,
- **Only 3 left** (with the real number) when stock is 1 to 4,

```jsx tests file=/StockLabel.test.js
import { render, screen } from "@testing-library/react";
import "@testing-library/jest-dom";
import StockLabel from "./StockLabel";

test("0 is sold out", () => {
  render(<StockLabel stock={0} />);
  expect(screen.getByText("Sold out")).toBeInTheDocument();
});

test("1 to 4 shows how many are left", () => {
  render(<StockLabel stock={3} />);
  expect(screen.getByText("Only 3 left")).toBeInTheDocument();
});

test("4 is still low", () => {
  render(<StockLabel stock={4} />);
  expect(screen.getByText("Only 4 left")).toBeInTheDocument();
});

test("5 or more renders nothing", () => {
  const { container } = render(<StockLabel stock={12} />);
  expect(container).toBeEmptyDOMElement();
});
```

```jsx solution file=/StockLabel.js
export default function StockLabel({ stock }) {
  if (stock === 0) return <span className="stock out">Sold out</span>;
  if (stock < 5) return <span className="stock low">Only {stock} left</span>;
  return null;
}
```
