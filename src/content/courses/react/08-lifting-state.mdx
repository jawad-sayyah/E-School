State lives in one component. So what happens when **two** components need it? The product list adds to the cart, and the header's badge shows the cart's size. They're siblings: neither can read the other's state.

<Concept name="The problem" id="problem">

Here the cart state lives inside `ProductList`. Clicking **Add** updates the list's own count, but `Header` has no way to know.

<ReactPlayground height={360}>

```jsx file=/App.js
import { useState } from "react";

function Header() {
  return <header>MiniShop · Cart: ?</header>;
}

function ProductList() {
  const [cart, setCart] = useState([]);
  return (
    <>
      <button onClick={() => setCart([...cart, "Coffee"])}>Add Coffee</button>
      <button onClick={() => setCart([...cart, "Tea"])}>Add Tea</button>
      <p>(ProductList knows: {cart.length} items)</p>
    </>
  );
}

export default function App() {
  return (
    <>
      <Header />
      <ProductList />
    </>
  );
}
```

</ReactPlayground>
</Concept>

<Concept name="Lift the state up" id="lift">

The fix has three steps:

1. **Move** the state to the **closest common parent** of everyone who needs it: here, `App`.
2. **Pass the data down** as props to the components that show it (`count` to `Header`).
3. **Pass a function down** to the components that change it (`onAdd` to `ProductList`). They call it; the parent updates its state.

<ReactPlayground height={380}>

```jsx file=/App.js
import { useState } from "react";

function Header({ count }) {
  return <header>MiniShop · Cart: {count}</header>;
}

function ProductList({ onAdd }) {
  return (
    <>
      <button onClick={() => onAdd("Coffee")}>Add Coffee</button>
      <button onClick={() => onAdd("Tea")}>Add Tea</button>
    </>
  );
}

function CartSummary({ items }) {
  if (items.length === 0) return <p>Your cart is empty.</p>;
  return <p>In your cart: {items.join(", ")}</p>;
}

export default function App() {
  const [cart, setCart] = useState([]);

  function handleAdd(name) {
    setCart([...cart, name]);
  }

  return (
    <>
      <Header count={cart.length} />
      <ProductList onAdd={handleAdd} />
      <CartSummary items={cart} />
    </>
  );
}
```

</ReactPlayground>

Now there's **one source of truth**: `App`'s `cart`. `Header`, `ProductList` and `CartSummary` hold no state of their own; they're simple functions of their props. Data flows **down** as props, and changes flow **up** through callbacks.

</Concept>

<Concept name="Don't copy props into state" id="no-copy">

A common mistake is to "save" a prop in state:

<Compare
  wrong="The state is set from the prop once, on the first render; later prop changes are ignored"
  right="Read the prop directly, or calculate from it during render"
  wrongFile="Badge.jsx"
  rightFile="Badge.jsx"
>

```jsx
function Badge({ count }) {
  const [shown, setShown] = useState(count);
  return <span>{shown}</span>;
}
```

```jsx
function Badge({ count }) {
  return <span>{count > 99 ? "99+" : count}</span>;
}
```

</Compare>

`useState(count)` only uses its argument on the **first** render. When the parent later passes a new `count`, `shown` keeps the old one. Anything you can calculate from props or other state should be a plain variable, not state.

</Concept>

<HowItWorks title="Deciding where state lives">

For each piece of state, ask:

1. **Which components show it or change it?** List them.
2. **What's their closest common parent?** Put the state there (or higher, if it makes more sense).
3. **Can it be calculated** from props or other state? Then it isn't state at all: compute it during render.

Lifting state up can mean passing props through several layers. When that gets painful ("prop drilling"), composition (next lesson) and Context (Hooks course) help.

</HowItWorks>

The badge in the header is stuck at 0, because the cart state lives inside `ProductList`. Lift it up to `App`, so the header shows the number of items added.

```jsx starter file=/App.js
import { useState } from "react";

function Header({ count }) {
  return (
    <header>
      MiniShop <span aria-label="Items in cart">{count}</span>
    </header>
  );
}

function ProductList() {
  const [cart, setCart] = useState([]);
  return (
    <>
      <button onClick={() => setCart([...cart, "Coffee"])}>Add Coffee</button>
      <button onClick={() => setCart([...cart, "Tea"])}>Add Tea</button>
    </>
  );
}

export default function App() {
  return (
    <>
      <Header count={0} />
      <ProductList />
    </>
  );
}
```

```jsx tests file=/App.test.js
import { fireEvent, render, screen } from "@testing-library/react";
import "@testing-library/jest-dom";
import App from "./App";

test("the badge starts at 0", () => {
  render(<App />);
  expect(screen.getByLabelText("Items in cart")).toHaveTextContent("0");
});

test("adding products updates the badge", () => {
  render(<App />);
  fireEvent.click(screen.getByRole("button", { name: "Add Coffee" }));
  fireEvent.click(screen.getByRole("button", { name: "Add Tea" }));
  fireEvent.click(screen.getByRole("button", { name: "Add Coffee" }));
  expect(screen.getByLabelText("Items in cart")).toHaveTextContent("3");
});
```

```jsx solution file=/App.js
import { useState } from "react";

function Header({ count }) {
  return (
    <header>
      MiniShop <span aria-label="Items in cart">{count}</span>
    </header>
  );
}

function ProductList({ onAdd }) {
  return (
    <>
      <button onClick={() => onAdd("Coffee")}>Add Coffee</button>
      <button onClick={() => onAdd("Tea")}>Add Tea</button>
    </>
  );
}

export default function App() {
  const [cart, setCart] = useState([]);
  return (
    <>
      <Header count={cart.length} />
      <ProductList onAdd={(name) => setCart([...cart, name])} />
    </>
  );
}
```
