React 19 also brings a set of smaller upgrades that remove whole libraries and workarounds from typical apps.

<Concept name="Title and meta tags from any component" id="metadata">

Render `<title>`, `<meta>` and `<link>` anywhere in your tree; React **hoists** them into the document's `<head>`. The page that knows its product can set its own title, with no effect and no helper library.

<ReactPlayground height={320}>

```jsx file=/App.js
import { useState } from "react";

function ProductPage({ product }) {
  return (
    <article>
      <title>{`${product.name} · MiniShop`}</title>
      <meta name="description" content={`Order ${product.name} online for $${product.price}.`} />
      <h2>{product.name}</h2>
      <p>${product.price}</p>
    </article>
  );
}

const PRODUCTS = [
  { id: 1, name: "Coffee", price: 4 },
  { id: 2, name: "Tea", price: 2 },
];

export default function App() {
  const [product, setProduct] = useState(PRODUCTS[0]);
  return (
    <>
      {PRODUCTS.map((p) => (
        <button key={p.id} onClick={() => setProduct(p)}>{p.name}</button>
      ))}
      <ProductPage product={product} />
      <p className="hint">The preview's tab title is now: {product.name} · MiniShop</p>
    </>
  );
}
```

</ReactPlayground>

Pass `<title>` a **single string** (a template literal), not mixed text and expressions: `<title>{name} · Shop</title>` would give the title element several children, which React warns about.

</Concept>

<Concept name="Stylesheets, scripts and preloading" id="resources">

- **Stylesheets:** `<link rel="stylesheet" href="/product.css" precedence="default" />` inside a component. React inserts it once, orders stylesheets by `precedence`, and waits for it to load before showing content that depends on it (with Suspense).
- **Async scripts:** `<script async src="https://maps.example.com/sdk.js" />` anywhere; React de-duplicates it, even if many components render it.
- **Resource hints** from `react-dom`: `preconnect(url)`, `prefetchDNS(url)`, `preload(url, { as })` and `preinit(url, { as })` tell the browser what it will need soon, so it can start early.

```jsx file=Checkout.jsx
import { preconnect, preinit } from "react-dom";

function Checkout() {
  preconnect("https://payments.example.com");
  preinit("https://payments.example.com/widget.js", { as: "script" });
  // …
}
```

</Concept>

<Concept name="Smaller upgrades you'll use" id="small-upgrades">

| Before React 19 | React 19 |
| --- | --- |
| `forwardRef((props, ref) => …)` | `ref` is a regular prop of function components |
| `<ThemeContext.Provider value={…}>` | `<ThemeContext value={…}>` |
| ref callbacks called with `null` on unmount | ref callbacks can **return a cleanup function** |
| vague hydration errors | one error with a diff of what didn't match |
| custom elements with limited prop support | full support for custom elements (Web Components) |

A ref callback with a cleanup looks like an effect:

```jsx file=Video.jsx
<video
  ref={(node) => {
    const observer = new IntersectionObserver(([e]) => (e.isIntersecting ? node.play() : node.pause()));
    observer.observe(node);
    return () => observer.disconnect(); // runs when the element is removed
  }}
/>
```

</Concept>

<HowItWorks title="Why hoisting and de-duplication matter">

Before React 19, a component couldn't put anything into `<head>` without a library (react-helmet) or an effect that wrote `document.title`, which flickered and didn't work for server rendering. Now the component that owns the data owns its metadata, and React makes sure it ends up in the right place, once, in the right order. It's the same idea as everything else in React: describe what you need, and React handles where and when.

</HowItWorks>

Make `ProductPage` set the browser tab's title to **Coffee · MiniShop** (for the current product) and a `<meta name="description">` with the product's summary, using React 19's metadata support.

```jsx starter file=/ProductPage.js
export default function ProductPage({ product }) {
  return (
    <article>
      <h2>{product.name}</h2>
      <p>{product.summary}</p>
    </article>
  );
}
```

```jsx starter file=/App.js
import ProductPage from "./ProductPage";

const coffee = { name: "Coffee", summary: "Freshly roasted, brewed to order." };

export default function App() {
  return <ProductPage product={coffee} />;
}
```

```jsx tests file=/ProductPage.test.js
import { render } from "@testing-library/react";
import "@testing-library/jest-dom";
import ProductPage from "./ProductPage";

const tea = { name: "Tea", summary: "Loose-leaf, steeped just right." };

test("sets the document title", () => {
  render(<ProductPage product={tea} />);
  expect(document.title).toBe("Tea · MiniShop");
});

test("adds a meta description to the head", () => {
  render(<ProductPage product={tea} />);
  const meta = document.head.querySelector('meta[name="description"]');
  expect(meta).not.toBeNull();
  expect(meta.getAttribute("content")).toBe("Loose-leaf, steeped just right.");
});
```

```jsx solution file=/ProductPage.js
export default function ProductPage({ product }) {
  return (
    <article>
      <title>{`${product.name} · MiniShop`}</title>
      <meta name="description" content={product.summary} />
      <h2>{product.name}</h2>
      <p>{product.summary}</p>
    </article>
  );
}
```
