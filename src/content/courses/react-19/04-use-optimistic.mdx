When you tap "Like" in a good app, the heart fills **instantly**, even though the server takes a moment. That's an **optimistic update**: show what you expect to happen, and correct it if the server disagrees. `useOptimistic` makes that safe and simple.

<Concept name="The hook" id="the-hook">

```jsx file=Likes.jsx
const [optimisticValue, addOptimistic] = useOptimistic(value, updateFn);
```

- `value` is the **real** state (from props or `useState`).
- While an Action is running, calling `addOptimistic(input)` shows `updateFn(currentValue, input)` instead.
- When the Action finishes, the optimistic value is thrown away and `optimisticValue` goes back to following `value`, which by then should hold the real result.

<ReactPlayground height={400}>

```jsx file=/App.js
import { useOptimistic, useState, startTransition } from "react";
import { sendReview } from "./api";

export default function App() {
  const [reviews, setReviews] = useState(["Great coffee!"]);
  const [shown, addOptimisticReview] = useOptimistic(reviews, (current, text) => [
    ...current,
    text + " (sending…)",
  ]);

  function submit(formData) {
    const text = formData.get("text");
    startTransition(async () => {
      addOptimisticReview(text);          // shows instantly
      const saved = await sendReview(text); // takes 1.5 s
      setReviews((r) => [...r, saved]);   // the real list
    });
  }

  return (
    <>
      <ul>
        {shown.map((r, i) => (
          <li key={i}>{r}</li>
        ))}
      </ul>
      <form action={submit}>
        <input name="text" placeholder="Write a review" required />
        <button>Post</button>
      </form>
    </>
  );
}
```

```js file=/api.js
export function sendReview(text) {
  return new Promise((resolve) => setTimeout(() => resolve(text), 1500));
}
```

<Concept name="Rollback for free" id="rollback">

If the Action **fails** (throws, or simply doesn't update `value`), the optimistic value disappears when the Action ends and the UI shows the real state again. You don't write any "undo" code; you only have to tell the user what happened:

```jsx file=LikeButton.jsx
function LikeButton({ likes, onLike }) {
  const [optimisticLikes, addLike] = useOptimistic(likes, (n) => n + 1);
  const [error, setError] = useState(null);

  function like() {
    startTransition(async () => {
      addLike();
      try {
        await onLike();          // the parent updates `likes` on success
      } catch {
        setError("Couldn't save your like.");  // the count falls back by itself
      }
    });
  }
  return <button onClick={like}>♥ {optimisticLikes}</button>;
}
```

</Concept>

<HowItWorks title="Optimistic state lives only during an Action">

`useOptimistic` keeps a list of pending optimistic updates. On each render it applies them, in order, on top of the latest real `value`. When the transition that added them finishes, React drops them. So the optimistic value can never get "stuck": it's always derived from the real state plus whatever is still in flight. That's also why `addOptimistic` must be called **inside** an Action (a transition or a form action); outside one, React warns and the update vanishes immediately.

</HowItWorks>

The server takes a moment to add to the cart, so the badge feels slow. Make it optimistic: the badge must go up **immediately** on click, and show the server's real count when it answers.

```jsx starter file=/App.js
import { useState } from "react";
import { addToCart } from "./api";

export default function App() {
  const [count, setCount] = useState(0);

  async function handleAdd() {
    const next = await addToCart();
    setCount(next);
  }

  return (
    <>
      <span aria-label="Items in cart">{count}</span>
      <button onClick={handleAdd}>Add to cart</button>
    </>
  );
}
```

```js starter file=/api.js
let serverCount = 0;

export function addToCart() {
  return new Promise((resolve) => setTimeout(() => resolve(++serverCount), 200));
}
```

```jsx tests file=/App.test.js
import { act, fireEvent, render, screen } from "@testing-library/react";
import "@testing-library/jest-dom";
import App from "./App";

const wait = (ms) => act(async () => {
  await new Promise((resolve) => setTimeout(resolve, ms));
});

test("the badge goes up immediately, before the server answers", async () => {
  render(<App />);
  const before = Number(screen.getByLabelText("Items in cart").textContent);
  fireEvent.click(screen.getByRole("button", { name: "Add to cart" }));
  await wait(20);
  expect(screen.getByLabelText("Items in cart")).toHaveTextContent(String(before + 1));
  await wait(300);
});

test("after the server answers, the real count is shown", async () => {
  render(<App />);
  fireEvent.click(screen.getByRole("button", { name: "Add to cart" }));
  await wait(300);
  const shown = Number(screen.getByLabelText("Items in cart").textContent);
  expect(shown).toBeGreaterThan(0);
});
```

```jsx solution file=/App.js
import { startTransition, useOptimistic, useState } from "react";
import { addToCart } from "./api";

export default function App() {
  const [count, setCount] = useState(0);
  const [optimisticCount, addOptimistic] = useOptimistic(count, (c) => c + 1);

  function handleAdd() {
    startTransition(async () => {
      addOptimistic();
      const next = await addToCart();
      setCount(next);
    });
  }

  return (
    <>
      <span aria-label="Items in cart">{optimisticCount}</span>
      <button onClick={handleAdd}>Add to cart</button>
    </>
  );
}
```
