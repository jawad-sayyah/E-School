---
id: prototypes
title: Prototypes
summary: How objects inherit from other objects through the prototype chain, and how classes are built on it.
minutes: 14
tags: [prototypes, prototype chain, Object.create, inheritance, instanceof, Object.hasOwn, classes]
---

Every object has a hidden link to another object, its **prototype**. When a property isn't on the object itself, JavaScript follows that link and looks there. Classes, array methods and `instanceof` are all built on this.

<Concept name="Every object has a prototype" id="object-prototype">

A plain object's prototype is `Object.prototype`, which is where methods like `toString` come from.

<Playground file="prototype.js" expected={["true", "[object Object]"]}>

```js
const item = { name: "Tea" };

console.log(Object.getPrototypeOf(item) === Object.prototype);
console.log(item.toString());   // not on item: found on the prototype
```

</Playground>
</Concept>

<Concept name="The prototype chain" id="prototype-chain">

`Object.create(proto)` makes an object whose prototype is `proto`, so it can use everything `proto` has without copying it.

<Playground file="chain.js" expected={["Hi from Sara", "false"]}>

```js
const base = {
  greet() {
    return `Hi from ${this.name}`;
  },
};

const user = Object.create(base);
user.name = "Sara";

console.log(user.greet());                // found on base
console.log(Object.hasOwn(user, "greet")); // not user's own property
```

</Playground>
</Concept>

<Concept name="Classes are prototypes underneath" id="classes-prototypes">

A class is a function, and its methods live on `Class.prototype`, shared by every object it creates.

<Playground file="class-proto.js" expected={["function", "true", "true"]}>

```js
class Cart {
  add() {}
}

const cart = new Cart();
console.log(typeof Cart);
console.log(Object.getPrototypeOf(cart) === Cart.prototype);
console.log(Object.hasOwn(Cart.prototype, "add"));
```

</Playground>
</Concept>

<Concept name="instanceof" id="instanceof">

`instanceof` checks whether a class's prototype is anywhere in an object's chain.

<Playground file="instanceof.js" expected={["true true false"]}>

```js
class Product {}
class Sale extends Product {}

const sale = new Sale();
console.log(sale instanceof Sale, sale instanceof Product, sale instanceof Array);
```

</Playground>
</Concept>

<Concept name="Array methods live on Array.prototype" id="array-prototype">

Your arrays don't each carry a copy of `map`; they all find it on `Array.prototype`.

<Playground file="array-proto.js" expected={["false", "true"]}>

```js
const prices = [1, 2];

console.log(Object.hasOwn(prices, "map"));
console.log(prices.map === Array.prototype.map);
```

</Playground>

<Callout type="warn">
Never add methods to built-in prototypes like `Array.prototype`: every array in the app (and in every library) gets them, and names can clash with future JavaScript features.
</Callout>
</Concept>

<HowItWorks title="Following the chain">

For `user.toString()`, JavaScript checks `user` itself, then `base` (user's prototype), then `Object.prototype` (base's prototype), where it finds `toString`. If it reached the end (`null`) without finding it, the result would be `undefined`.

</HowItWorks>

<GoDeeper title="Own properties vs inherited ones">

Some tools only look at an object's **own** properties, others follow the chain:

<Playground file="own.js" expected={["[ 'name' ]", "true", "false", "true"]}>

```js
const base = { greet() {} };
const user = Object.create(base);
user.name = "Sara";

console.log(Object.keys(user));            // own, enumerable keys only
console.log("greet" in user);              // `in` follows the chain
console.log(Object.hasOwn(user, "greet")); // own only
console.log(Object.hasOwn(user, "name"));
```

</Playground>

`JSON.stringify`, spread and `Object.keys` only copy own properties, which is why a class instance loses its methods when you spread it into a plain object.

</GoDeeper>

<Exercise
  id="shared-methods"
  title="Share a method through a prototype"
  hints={[
    "Put `label()` on `productProto`; inside it, use `this.name` and `this.price`.",
    "In `makeProduct`, create the object with `Object.create(productProto)`, then set `name` and `price` on it.",
  ]}
>

Give every product a `label()` method without copying it onto each object. Fill in `productProto` and `makeProduct(name, price)`; `label()` returns text like `"Tea: $2.00"`.

```js starter
const productProto = {};

function makeProduct(name, price) {
  return { name, price };
}

console.log(makeProduct("Tea", 2).label());
```

```js tests
test("label() formats the product", () => {
  expect(makeProduct("Tea", 2).label()).toBe("Tea: $2.00");
});

test("label is inherited, not copied", () => {
  const p = makeProduct("Tea", 2);
  expect(Object.hasOwn(p, "label")).toBe(false);
});

test("all products share one label function", () => {
  expect(makeProduct("A", 1).label).toBe(makeProduct("B", 2).label);
});
```

```js solution
const productProto = {
  label() {
    return `${this.name}: $${this.price.toFixed(2)}`;
  },
};

function makeProduct(name, price) {
  const product = Object.create(productProto);
  product.name = name;
  product.price = price;
  return product;
}

console.log(makeProduct("Tea", 2).label());
```

</Exercise>
