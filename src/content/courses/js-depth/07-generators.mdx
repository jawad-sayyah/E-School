title: Iterators & generators

`for...of`, spread (`[...x]`) and array destructuring all work the same way underneath: they ask a value for an **iterator** and pull items from it one at a time. **Generator functions** are the easy way to make your own.

<Concept name="Iterables" id="iterables">

Arrays, strings, Maps and Sets are all **iterable**: `for...of` can walk through them.

<Playground file="iterables.js" expected={["T", "e", "a"]}>

```js
for (const letter of "Tea") {
  console.log(letter);
}
```

</Playground>
</Concept>

<Concept name="The iterator protocol" id="iterator-protocol">

An iterator has a `next()` method that returns `{ value, done }`; `for...of` just calls it until `done` is true.

<Playground file="protocol.js" expected={["{ value: 'a', done: false }", "{ value: 'b', done: false }", "{ value: undefined, done: true }"]}>

```js
const it = ["a", "b"][Symbol.iterator]();

console.log(it.next());
console.log(it.next());
console.log(it.next());
```

</Playground>
</Concept>

<Concept name="function* and yield" id="generators">

A generator function (`function*`) can pause at each `yield` and hand back a value; it continues from there on the next request.

<Playground file="generator.js" expected={["[ 1, 2, 3 ]"]}>

```js
function* countUp() {
  yield 1;
  yield 2;
  yield 3;
}

console.log([...countUp()]);
```

</Playground>
</Concept>

<Concept name="Generators are lazy" id="lazy">

A generator only runs when asked for the next value, so it can even describe an endless sequence.

<Playground file="ids.js" expected={["1 2 3"]}>

```js
function* ids() {
  let id = 1;
  while (true) yield id++;   // endless, but only runs on demand
}

const nextId = ids();
console.log(nextId.next().value, nextId.next().value, nextId.next().value);
```

</Playground>
</Concept>

<Concept name="Make your own iterable" id="custom-iterable">

Give an object a `[Symbol.iterator]` method (a generator is easiest) and `for...of` works on it.

<Playground file="iterable-class.js" expected={["Coffee", "Tea"]}>

```js
class Cart {
  items = ["Coffee", "Tea"];
  *[Symbol.iterator]() {
    yield* this.items;   // hand over every item of the array
  }
}

for (const item of new Cart()) {
  console.log(item);
}
```

</Playground>
</Concept>

<Concept name="Spread and destructuring use iteration" id="spread-iteration">

Anything iterable works with spread and array destructuring, including generators.

<Playground file="destructure.js" expected={["x [ 'y', 'z' ]"]}>

```js
function* letters() {
  yield "x";
  yield "y";
  yield "z";
}

const [first, ...rest] = letters();
console.log(first, rest);
```

</Playground>
</Concept>

<GoDeeper title="Async generators and for await">

An `async function*` can `await` inside and `yield` values as they arrive; you read it with `for await`. It's a neat fit for paging through an API:

<Playground file="async-gen.js" expected={["page 1: 3 products", "page 2: 3 products"]}>

```js
async function* pages() {
  for (let page = 1; page <= 2; page++) {
    const res = await fetch("/api/products");
    const products = await res.json();
    yield `page ${page}: ${products.length} products`;
  }
}

for await (const line of pages()) {
  console.log(line);
}
```

</Playground>

</GoDeeper>

<Exercise
  id="range-generator"
  title="A range generator"
  hints={[
    "Write it as `function* range(start, end, step = 1)`.",
    "Use a `for` loop from `start` while `i < end`, adding `step`, and `yield i` each time.",
  ]}
>

Write a generator `range(start, end, step = 1)` that yields numbers from `start` up to (not including) `end`, going up by `step`.

```js starter
function range(start, end, step = 1) {
  return [];
}

console.log([...range(1, 4)]);
```

```js tests
test("counts from start up to end", () => {
  expect([...range(1, 4)]).toEqual([1, 2, 3]);
});

test("uses the step", () => {
  expect([...range(0, 10, 5)]).toEqual([0, 5]);
});

test("is empty when start isn't below end", () => {
  expect([...range(3, 3)]).toEqual([]);
});

test("is a generator (has a next method)", () => {
  expect(typeof range(0, 1).next).toBe("function");
});
```

```js solution
function* range(start, end, step = 1) {
  for (let i = start; i < end; i += step) {
    yield i;
  }
}

console.log([...range(1, 4)]);
```

</Exercise>
