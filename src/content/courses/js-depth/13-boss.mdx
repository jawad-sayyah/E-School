<Exercise
  id="boss-inventory"
  title="An inventory with rules"
  hints={[
    "Keep stock in a private Map: `#stock = new Map();`.",
    "`remove` should throw `new RangeError(\"Not enough \" + name)` when there isn't enough.",
    "`get names()` can return `[...this.#stock.keys()].toSorted()`.",
  ]}
>

Write a class `Inventory` with `add(name, qty)`, `remove(name, qty)`, `count(name)` (0 for unknown items) and a `names` getter (item names, sorted A–Z). Removing more than is in stock throws a `RangeError` whose message contains `Not enough`. Keep the stock private.

```js starter
class Inventory {
}
```

```js tests
test("adds and counts", () => {
  const inv = new Inventory();
  inv.add("Tea", 3);
  inv.add("Tea", 2);
  expect(inv.count("Tea")).toBe(5);
  expect(inv.count("Cake")).toBe(0);
});

test("removes stock", () => {
  const inv = new Inventory();
  inv.add("Tea", 3);
  inv.remove("Tea", 2);
  expect(inv.count("Tea")).toBe(1);
});

test("refuses to remove more than there is", () => {
  const inv = new Inventory();
  inv.add("Tea", 1);
  expect(() => inv.remove("Tea", 2)).toThrow(RangeError);
  expect(() => inv.remove("Cake", 1)).toThrow("Not enough");
});

test("lists names sorted", () => {
  const inv = new Inventory();
  inv.add("Tea", 1);
  inv.add("Cake", 1);
  expect(inv.names).toEqual(["Cake", "Tea"]);
});

test("keeps the stock private", () => {
  expect(Object.keys(new Inventory())).toEqual([]);
});
```

```js solution
class Inventory {
  #stock = new Map();
  add(name, qty) {
    this.#stock.set(name, this.count(name) + qty);
  }
  remove(name, qty) {
    if (this.count(name) < qty) throw new RangeError(`Not enough ${name}`);
    this.#stock.set(name, this.count(name) - qty);
  }
  count(name) {
    return this.#stock.get(name) ?? 0;
  }
  get names() {
    return [...this.#stock.keys()].toSorted();
  }
}
```

<Exercise

  title="Load and sort the catalog"
  hints={[

Write `async function cheapestFirst(url = "/api/products")` that loads the products and returns their names, cheapest first. Throw an error with the message `HTTP <status>` when the response isn't ok.

```js starter
async function cheapestFirst(url = "/api/products") {
  return [];
}
```

```js tests
test("returns names, cheapest first", async () => {
  expect(await cheapestFirst()).toEqual(["Bagel", "Coffee", "Muffin"]);
});

test("throws for a bad response", async () => {
  let message = "no error";
  try {
    await cheapestFirst("/api/missing");
  } catch (err) {
    message = err.message;
  }
  expect(message).toBe("HTTP 404");
});
```

```js solution
async function cheapestFirst(url = "/api/products") {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  const products = await res.json();
  return products.toSorted((a, b) => a.price - b.price).map((p) => p.name);
}
```

<Exercise
  id="boss-slugify"
  title="Product slugs"
  hints={[
    "Lowercase and trim first.",
    "Replace every run of characters that aren't letters or digits with one dash: `/[^a-z0-9]+/g`.",
    "Remove dashes at the start and end: `/^-|-$/g`.",
  ]}
>

Write `slugify(name)` that turns a product name into a URL slug: lowercase, words joined by single dashes, no dashes at either end, and only letters, digits and dashes.

```js starter
function slugify(name) {
  return name.toLowerCase().replace(" ", "-");
}
```

```js tests
test("joins words with dashes", () => {
  expect(slugify("Iced Coffee")).toBe("iced-coffee");
});

test("removes symbols and extra spaces", () => {
  expect(slugify("  Iced   Coffee (Large)! ")).toBe("iced-coffee-large");
});

test("keeps digits", () => {
  expect(slugify("Mug 2.0")).toBe("mug-2-0");
});
```

```js solution
function slugify(name) {
  return name
    .toLowerCase()
    .trim()
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-|-$/g, "");
}
```

</Exercise>
