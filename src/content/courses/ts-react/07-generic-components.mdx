Some components don't care what they display: a list, a table, a dropdown. With `any`, their callbacks would lose the item type. A **generic component** keeps it: `List<Product>` calls `renderItem` with a `Product`.

<Concept name="A generic List" id="list">

<TSPlayground file="List.tsx" errors={[21]} checkOnly>

```tsx
import type { ReactNode, Key } from "react";

type ListProps<T> = {
  items: T[];
  getKey: (item: T) => Key;
  renderItem: (item: T) => ReactNode;
  empty?: ReactNode;
};

function List<T>({ items, getKey, renderItem, empty = <p>Nothing here.</p> }: ListProps<T>) {
  if (items.length === 0) return <>{empty}</>;
  return <ul>{items.map((item) => <li key={getKey(item)}>{renderItem(item)}</li>)}</ul>;
}

type Product = { id: number; name: string; price: number };
const products: Product[] = [{ id: 1, name: "Coffee", price: 4 }];

const ok = (
  <List items={products} getKey={(p) => p.id} renderItem={(p) => `${p.name} · $${p.price}`} />
);
const typo = <List items={products} getKey={(p) => p.id} renderItem={(p) => p.title} />; // error
const words = <List items={["hot", "iced"]} getKey={(w) => w} renderItem={(w) => w.toUpperCase()} />;
```

</TSPlayground>

`T` is inferred from `items`, so `p` is a `Product` in the callbacks, and `w` is a `string` in the last list. No type arguments needed at the call site.

</Concept>

<Concept name="A generic Select with a value type" id="select">

```tsx file=Select.tsx
type Option<V extends string> = { value: V; label: string };

function Select<V extends string>({ options, value, onChange }: {
  options: Option<V>[];
  value: V;
  onChange: (value: V) => void;
}) {
  return (
    <select value={value} onChange={(e) => onChange(e.target.value as V)}>
      {options.map((o) => <option key={o.value} value={o.value}>{o.label}</option>)}
    </select>
  );
}

type Size = "small" | "medium" | "large";
const sizes: Option<Size>[] = [{ value: "small", label: "Small" }, { value: "large", label: "Large" }];
<Select options={sizes} value="small" onChange={(size) => setSize(size)} />;  // size: Size
```

The `as V` is safe here because the options are the only values the `<select>` can produce.

</Concept>

<HowItWorks title="Generic components are generic functions">

A component is a function, so `function List<T>(props: ListProps<T>)` is just a generic function, and `<List items={products} … />` is a call whose arguments TypeScript uses to infer `T`. If inference can't work it out, you can even pass the type argument in JSX: `<List<Product> items={[]} … />`. (In `.tsx` files, arrow-function generics need a trailing comma, `<T,>(props: ListProps<T>) => …`, so the `<T>` isn't read as a JSX tag; `function` declarations avoid that.)

</HowItWorks>

<TSExercise
  id="generic-picker"
  title="A generic Picker"
  hints={[
    "`type PickerProps<T> = { items: T[]; getLabel: (item: T) => string; onPick: (item: T) => void };`",

Make `Picker` generic: it renders a button per item, labels it with `getLabel(item)`, and calls `onPick(item)` with the **typed** item when clicked.

```tsx starter
type PickerProps = { items: any[]; getLabel: (item: any) => string; onPick: (item: any) => void };

export function Picker({ items, getLabel, onPick }: PickerProps) {
  return (
    <div role="group">
      {items.map((item, i) => (
        <button key={i} onClick={() => onPick(item)}>{getLabel(item)}</button>
      ))}
    </div>
  );
}
```

```tsx types
type Product = { id: number; name: string; price: number };
const products: Product[] = [{ id: 1, name: "Tea", price: 2 }];
const ok = <Picker items={products} getLabel={(p) => p.name} onPick={(p) => console.log(p.price.toFixed(2))} />;
const sizes = <Picker items={["S", "M"]} getLabel={(s) => s} onPick={(s) => s.toLowerCase()} />;
// @ts-expect-error products have no "title"
const typo = <Picker items={products} getLabel={(p) => p.title} onPick={() => {}} />;
// @ts-expect-error onPick gets a Product, not a number
const wrong = <Picker items={products} getLabel={(p) => p.name} onPick={(p: number) => p} />;
```

```tsx solution
type PickerProps<T> = { items: T[]; getLabel: (item: T) => string; onPick: (item: T) => void };

export function Picker<T>({ items, getLabel, onPick }: PickerProps<T>) {
  return (
    <div role="group">
      {items.map((item, i) => (
        <button key={i} onClick={() => onPick(item)}>{getLabel(item)}</button>
      ))}
    </div>
  );
}
```
