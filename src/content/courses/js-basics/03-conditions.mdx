Programs make decisions: show "Cart is empty" or a list, charge shipping or not. Conditions pick which code runs.

<Concept name="if / else" id="if-else">

`if` runs code only when a condition is true, and `else` runs when it isn't.

<Playground file="if-else.js" expected={["Cart is empty"]}>

```js
const qty = 0;

if (qty === 0) {
  console.log("Cart is empty");
} else {
  console.log(`${qty} items`);
}
```

</Playground>
</Concept>

<Concept name="else if" id="else-if">

Chain `else if` to check several conditions in order; the first one that's true wins.

<Playground file="else-if.js" expected={["Free shipping"]}>

```js
const total = 64;

if (total === 0) {
  console.log("Nothing to ship");
} else if (total >= 50) {
  console.log("Free shipping");
} else {
  console.log("Shipping: $4.99");
}
```

</Playground>
</Concept>

<Concept name="condition ? a : b" id="ternary" react>

The ternary is a one-line if/else that gives back a value. You'll use it inside JSX all the time.

<Playground file="ternary.js" expected={["3 items", "1 item"]}>

```js
const label = (qty) => (qty === 1 ? "item" : "items");

console.log(`3 ${label(3)}`);
console.log(`1 ${label(1)}`);
```

</Playground>
</Concept>

<Concept name="&& and ||" id="and-or" react>

`&&` gives the right side only if the left side is truthy. `||` gives a fallback when the left side is falsy.

<Playground file="and-or.js" expected={["Welcome back!", "Guest", "false"]}>

```js
const isLoggedIn = true;

console.log(isLoggedIn && "Welcome back!");
console.log("" || "Guest");
console.log(false && "never shown");
```

</Playground>
</Concept>

<Concept name="! (not)" id="not">

`!` flips true to false and false to true. It's handy for "if the cart is not empty".

<Playground file="not.js" expected={["false", "Show the cart"]}>

```js
const cartIsEmpty = false;

console.log(!true);
if (!cartIsEmpty) {
  console.log("Show the cart");
}
```

</Playground>
</Concept>

<Concept name="switch">

`switch` picks one branch out of many by matching a value. Reducers in React use it.

<Playground file="switch.js" expected={["Adding item"]}>

```js
const action = "add";

switch (action) {
  case "add":
    console.log("Adding item");
    break;
  case "remove":
    console.log("Removing item");
    break;
  default:
    console.log("Unknown action");
}
```

</Playground>

<Callout type="warn">
Forget `break` and the code falls through into the next `case` too.
</Callout>
</Concept>

<GoDeeper title="&& and || return values, not just true or false">

`&&` and `||` don't turn their result into `true` or `false`. They return **one of the two values** you gave them:

- `a && b`: if `a` is falsy, the result is `a` itself; otherwise it's `b`.
- `a || b`: if `a` is truthy, the result is `a` itself; otherwise it's `b`.

<Playground file="short-circuit.js" expected={["0", "Guest", "null", "Sara"]}>

```js
console.log(0 && "never");        // 0 is falsy: you get 0
console.log("" || "Guest");       // "" is falsy: you get "Guest"
const user = null;
console.log(user && user.name);   // stops at null
console.log({ name: "Sara" }.name || "Guest");
```

</Playground>

This is also why they "short-circuit": once the answer is known, the right side never runs. In React, `{count > 0 && <Badge />}` works because of this, but watch out for `{count && <Badge />}`: when `count` is `0`, React renders the `0`.

</GoDeeper>

<Exercise
  id="shipping-cost"
  title="Shipping cost"
  hints={[
    "Check the empty cart first: if the total is 0, return 0.",
    "Then check `total >= 50`. Everything else costs 4.99.",
  ]}
>

Write `shippingCost(total)`: an empty cart (total `0`) ships for `0`, a total of 50 or more ships free (`0`), and anything else costs `4.99`.

```js starter
function shippingCost(total) {
  return 4.99;
}

console.log(shippingCost(20));
```

```js tests
test("empty cart: no shipping", () => {
  expect(shippingCost(0)).toBe(0);
});

test("small order pays 4.99", () => {
  expect(shippingCost(20)).toBe(4.99);
});

test("exactly 50 ships free", () => {
  expect(shippingCost(50)).toBe(0);
});

test("big order ships free", () => {
  expect(shippingCost(120)).toBe(0);
});
```

```js solution
function shippingCost(total) {
  if (total === 0) return 0;
  if (total >= 50) return 0;
  return 4.99;
}

console.log(shippingCost(20));
```

</Exercise>
