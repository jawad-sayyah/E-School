<CodeReview
  id="review-get-names"
  answer={1}
  prompt="Which `getNames(cart)` would you approve? (Arrays I)"
  reasons={[
    "It works, but it's five lines of bookkeeping (a counter, an empty array, push) for something `map` does in one.",
    "One line, no counter, no mutation: `map` says exactly what it does. This is how React code renders lists.",
    "`forEach` always returns `undefined`, so this function returns `undefined` no matter what.",
  ]}
>

```js
function getNames(cart) {
  const names = [];
  for (let i = 0; i < cart.length; i++) {
    names.push(cart[i].name);
  }
  return names;
}
```

```js
const getNames = (cart) => cart.map((item) => item.name);
```

```js
function getNames(cart) {
  return cart.forEach((item) => item.name);
}
```

<Exercise
  id="cart-summary"
  title="Cart summary"
  hints={[
    "Handle the empty cart first with an early return.",
    "You need two totals: the number of items (sum of `qty`) and the price (sum of `price * qty`). `reduce` does both.",

  ]}
>

Write `cartSummary(cart)` that returns a summary like `"3 items · $11.00"`. Count items by their `qty`, use "item" for exactly one, and return `"Your cart is empty"` for an empty cart.

```js starter
function cartSummary(cart) {
  return "";
}

console.log(cartSummary([{ name: "Coffee", price: 4, qty: 2 }]));
```

```js tests
test("an empty cart", () => {
  expect(cartSummary([])).toBe("Your cart is empty");
});

test("one item uses the singular", () => {
  expect(cartSummary([{ name: "Coffee", price: 4, qty: 1 }])).toBe("1 item · $4.00");
});

test("several items, counted by qty", () => {
  const cart = [
    { name: "Coffee", price: 4, qty: 2 },
    { name: "Bagel", price: 3, qty: 1 },
  ];
  expect(cartSummary(cart)).toBe("3 items · $11.00");
});

test("decimal prices get two decimals", () => {
  expect(cartSummary([{ name: "Tea", price: 2.5, qty: 2 }])).toBe("2 items · $5.00");
});
```

```js solution
function cartSummary(cart) {
  if (cart.length === 0) return "Your cart is empty";
  const count = cart.reduce((n, item) => n + item.qty, 0);
  const total = cart.reduce((sum, item) => sum + item.price * item.qty, 0);
  const label = count === 1 ? "item" : "items";
  return `${count} ${label} · $${total.toFixed(2)}`;
}

console.log(cartSummary([{ name: "Coffee", price: 4, qty: 2 }]));
```
