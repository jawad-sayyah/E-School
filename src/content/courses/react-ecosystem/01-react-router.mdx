A real shop has pages: home, products, a product's details, the cart. Each has its own **URL** you can bookmark and share, and the Back button works. React has no router built in; **React Router** is the most widely used one (this site runs on it).

<Concept name="Routes, links and layouts" id="routes">

You describe the pages as a tree of **routes**: each maps a URL `path` to an `element`. A parent route renders an **`<Outlet />`** where its matching child goes, so the header and navigation are written once.

<ReactPlayground height={440}>

```jsx file=/App.js
import { useState } from "react";
import { createMemoryRouter, RouterProvider, Link, NavLink, Outlet, useLocation, useParams } from "react-router";

const PRODUCTS = [
  { id: "coffee", name: "Coffee", price: 4 },
  { id: "tea", name: "Tea", price: 2 },
];

function Layout() {
  const { pathname } = useLocation();
  return (
    <>
      <p className="url">URL: {pathname}</p>
      <nav>
        <NavLink to="/" end>Home</NavLink> <NavLink to="/products">Products</NavLink>
      </nav>
      <Outlet /> {/* the matching child route renders here */}
    </>
  );
}

function Home() {
  return <h2>Welcome to MiniShop</h2>;
}

function Products() {
  return (
    <ul>
      {PRODUCTS.map((p) => (
        <li key={p.id}><Link to={`/products/${p.id}`}>{p.name}</Link></li>
      ))}
    </ul>
  );
}

function ProductPage() {
  const { id } = useParams(); // "coffee" for /products/coffee
  const product = PRODUCTS.find((p) => p.id === id);
  if (!product) return <p>Product not found.</p>;
  return <h2>{product.name} · ${product.price}</h2>;
}

const routes = [
  {
    path: "/",
    element: <Layout />,
    children: [
      { index: true, element: <Home /> },
      { path: "products", element: <Products /> },
      { path: "products/:id", element: <ProductPage /> },
      { path: "*", element: <p>Page not found.</p> },
    ],
  },
];

export default function App() {
  // In a real app: createBrowserRouter(routes), which uses the browser's address bar
  const [router] = useState(() => createMemoryRouter(routes));
  return <RouterProvider router={router} />;
}
```

- **`<Link to="/products">`** navigates without reloading the page. Never use `<a href>` for in-app links: it reloads everything and loses state.
- **`<NavLink>`** is a Link that knows when it's active (it gets an `active` class), perfect for menus. `end` makes `/` match only exactly.
- **`:id`** in a path is a **URL parameter**; `useParams()` reads it.
- **`index: true`** is the child shown at the parent's own URL; **`path: "*"`** catches everything else (a 404 page).

</Concept>

<Concept name="Navigating in code, and search params" id="navigate">

```jsx file=Checkout.jsx
import { useNavigate, useSearchParams } from "react-router";

function CheckoutButton() {
  const navigate = useNavigate();
  async function checkout() {
    const orderId = await placeOrder();
    navigate(`/orders/${orderId}`);   // after an action, not on render
  }
  return <button onClick={checkout}>Place order</button>;
}

function ProductFilters() {
  // /products?sort=price&hot=1 : state that lives in the URL, so it can be shared
  const [params, setParams] = useSearchParams();
  const sort = params.get("sort") ?? "name";
  return (
    <select value={sort} onChange={(e) => setParams({ sort: e.target.value })}>
      <option value="name">Name</option>
      <option value="price">Price</option>
    </select>
  );
}
```

Filters, sorting, pagination and the open tab are good candidates for **search params**: they survive a reload and can be shared as a link.

</Concept>

<HowItWorks title="How client-side routing works">

The router listens to the URL. A `<Link>` click is intercepted: instead of asking the server for a new page, the router calls `history.pushState` to change the address bar, then re-renders `<RouterProvider>` with the new location. It **matches** the URL against your route tree (most specific match wins), and renders the matching route elements from the outermost layout down, each one's `<Outlet />` showing the next. The Back button fires a `popstate` event, and the router re-matches. The server only needs to send `index.html` for every URL (the deploy step of the MiniShop project sets that up).

</HowItWorks>

<GoDeeper title="Loaders: fetch data before the page renders">

React Router's data APIs let each route declare a `loader` that runs **before** its page renders, and the page reads the result with `useLoaderData()`. Navigation waits for the data (and `useNavigation().state` tells you it's loading), so pages never flash an empty state:

```jsx file=routes.jsx
{
  path: "products/:id",
  loader: async ({ params }) => fetchProduct(params.id),
  element: <ProductPage />,
}

function ProductPage() {
  const product = useLoaderData();
  return <h2>{product.name}</h2>;
}
```

Loaders, `action`s for forms, and lazy routes turn the router into a small data framework. TanStack Query (next lesson) is the other popular way to load data, and the two combine well.

</GoDeeper>

The product list links to `/products/coffee` and `/products/tea`, but there's no route for them yet. Add a `products/:id` route whose page shows the product's **name as a heading** and its **price**, shows **Product not found.** for an unknown id, and has a **Back to menu** link.

```jsx starter file=/App.js
import { useState } from "react";
import { createMemoryRouter, RouterProvider, Link } from "react-router";

export const PRODUCTS = [
  { id: "coffee", name: "Coffee", price: 4 },
  { id: "tea", name: "Tea", price: 2 },
];

function Menu() {
  return (
    <ul>
      {PRODUCTS.map((p) => (
        <li key={p.id}>
          <Link to={`/products/${p.id}`}>{p.name}</Link>
        </li>
      ))}
    </ul>
  );
}

function ProductPage() {
  return <h2>Product</h2>;
}

const routes = [{ path: "/", element: <Menu /> }];

export default function App({ initialPath = "/" }) {
  const [router] = useState(() => createMemoryRouter(routes, { initialEntries: [initialPath] }));
  return <RouterProvider router={router} />;
}
```

```jsx solution file=/App.js
import { useState } from "react";
import { createMemoryRouter, RouterProvider, Link, useParams } from "react-router";

export const PRODUCTS = [
  { id: "coffee", name: "Coffee", price: 4 },
  { id: "tea", name: "Tea", price: 2 },
];

function Menu() {
  return (
    <ul>
      {PRODUCTS.map((p) => (
        <li key={p.id}>
          <Link to={`/products/${p.id}`}>{p.name}</Link>
        </li>
      ))}
    </ul>
  );
}

function ProductPage() {
  const { id } = useParams();
  const product = PRODUCTS.find((p) => p.id === id);
  return (
    <>
      {product ? (
        <>
          <h2>{product.name}</h2>
          <p>${product.price}</p>
        </>
      ) : (
        <p>Product not found.</p>
      )}
      <Link to="/">Back to menu</Link>
    </>
  );
}

const routes = [
  { path: "/", element: <Menu /> },
  { path: "/products/:id", element: <ProductPage /> },
];

export default function App({ initialPath = "/" }) {
  const [router] = useState(() => createMemoryRouter(routes, { initialEntries: [initialPath] }));
  return <RouterProvider router={router} />;
}
```
